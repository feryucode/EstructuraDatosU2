# EstructuraDatosU2
# Ejercicios de Colas en Python

Este repositorio contiene dos programas que utilizan la estructura de datos **Cola (FIFO)**.

## Ejercicios

- **Ejercicio 1:** Suma los elementos de dos colas y guarda los resultados en una nueva cola.
- **Ejercicio 2:** Simula un sistema de atención de clientes para una compañía de seguros mediante turnos por servicio.

## Ejecución

Requiere Python 3.

```bash
python ejercicio1_suma_colas.py
python ejercicio2_seguros.py
```
